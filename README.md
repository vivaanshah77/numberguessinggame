# Number Guessing Game 
## Project Description 
This is a terminal-based number guessing game using Python. The program generates a random number based on the selected difficulty level, and the player attempts to guess it. After each guess, feedback is given indicating whether the guess is too high, too low, or correct. The game continues until the player guesses correctly or runs out of attempts and has the option to play again 

## Whats in it 

This program has random number generation across three difficulty levels: Easy (1–50 with 10 attempts), Medium (1–100 with 8 attempts), and Hard (1–500 with 7 attempts). To keep the game challenging, the players must guess the secret number within a limited number of attempts. The game provides a feedback system that guides the player by indicating if their guess is "Too high," "Too low," or "Correct." The game continues until the player guesses correctly or runs out of attempts and has the option to play again
